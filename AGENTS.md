# dice-lyrics-ai

## Agent skills

### Issue tracker

Issues and specs live as GitHub issues on `YungDice/dice-lyrics-ai`, managed via the `gh` CLI. See `docs/agents/issue-tracker.md`.

### Triage labels

Uses the canonical five labels as-is: `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context layout: `CONTEXT.md` + `docs/adr/` at the repo root. See `docs/agents/domain.md`.
